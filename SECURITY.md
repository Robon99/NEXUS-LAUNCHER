# Security Policy

## Supported versions

NEXUS Launcher is an experimental project. Security fixes are currently made against the latest source on the default branch. There are no formal release-level support guarantees yet.

## Reporting a vulnerability

Please do not publish passwords, Microsoft tokens, refresh tokens, API keys, or exploitable vulnerability details in a public issue.

If GitHub Private Vulnerability Reporting is enabled for this repository, use the repository's **Security → Report a vulnerability** page. Otherwise, contact the repository owner through their GitHub profile and request a private channel.

Please include:

- affected version or commit;
- Windows version and architecture;
- a concise description of the issue;
- safe reproduction steps;
- potential impact.

Do not send real account credentials or live access tokens.
